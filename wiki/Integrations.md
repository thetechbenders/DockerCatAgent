# Knowledge integrations

Mem and Obsidian are **optional**. Obsidian uses read-only filesystem mounts unless explicitly switched to write; Mem uses user-local MCP OAuth. Neither source is imported automatically.

Read the [Obsidian](../docs/obsidian-integration.md) and [Mem](../docs/mem-integration.md) setup guides. Future recipes must explicitly document scopes, data boundaries and redaction.
